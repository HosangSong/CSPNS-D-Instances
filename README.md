# CSPNS-D Instances
A repository with instances for the CSPNS using Drones

The Covering Salesman Problem with Nodes and Segments using Drones (CSPNS-D) is a variant of the classic Traveling Salesman Problem where a single truck with multiple drones collaborate for delivery. It was introduced for demonstrating a covering paradigm for truck-drone routing with En-route drone operation, where drones are launched on a moving truck.
